# 🧭 أدلة المشاكل العشر — ماذا تغيّر لكل مشكلة

لكل مشكلة: ما تضعه في `domain.yaml`، تنظيم البيانات، إعدادات `.env` المقترحة، أسئلة تقييم مميزة، وميزة البونص/الابتكار الأسرع تنفيذاً.
> المبدأ: **لا تكتب كوداً جديداً إلا لميزة البونص**. كل الباقي إعدادات + محتوى.

---

## 1) المرشد الأكاديمي الذكي — سهل (التعليم)
- **persona:** "أنت مرشد أكاديمي لطلبة [الجامعة]، تجيب من دليل الطالب واللوائح والخطط الدراسية."
- **system_prompt_extra:** "اذكر رقم المادة/البند ورمز المساق كما في المصدر. عند ذكر متطلبات سابقة اعرضها كقائمة. إذا اختلفت الخطة حسب سنة الالتحاق اسأل الطالب عن سنته."
- **البيانات:** `raw/regulations/`, `raw/study-plans/<major>/`, `raw/faq/` ← فلتر `category` = التخصص.
- **.env:** `CHUNK_SIZE=700`, `HYBRID_ALPHA=0.4` (رموز مساقات مثل CS201 ← BM25 مهم).
- **تقييم مميز:** "شو المتطلب السابق لـ ...؟" (جدول)، "كم ساعة لازم أخلص لأتخرج من هندسة؟".
- **بونص سريع:** لوحة "الأسئلة الأكثر تكراراً" موجودة أصلاً في التحليلات (أعد تسميتها) + فلتر التخصص في الواجهة.

## 2) المساعد القانوني والإجرائي — متوسط
- **system_prompt_extra:** "اذكر دائماً رقم المادة واسم القانون وسنته. ميّز بين النص الأصلي والتعديل، واعتمد الأحدث مع ذكر ذلك. أنهِ كل إجابة بتنبيه أنها ليست استشارة قانونية. للإجراءات أعطِ خطوات مرقمة."
- **disclaimer:** "هذه معلومات عامة وليست استشارة قانونية."
- **البيانات:** مجلد لكل قانون، و`2019/` `2023/` للإصدارات. التقطيع يحترم "المادة N" تلقائياً.
- **.env:** `CHUNK_SIZE=1000`, `HYBRID_ALPHA=0.35`.
- **تقييم مميز:** سؤال تعارض (مادة معدلة)، "خطوات تسجيل شركة".
- **بونص:** زر "حوّل الإجابة إلى Checklist" ← `POST /api/chat` بسؤال: "حوّل الإجراءات السابقة إلى قائمة خطوات مرقمة مع الوثائق المطلوبة" (بدون كود backend جديد).

## 3) مساعد المزارع — متوسط (الزراعة)
- **persona:** "مهندس زراعي يشرح للمزارع بلغة بسيطة."
- **system_prompt_extra:** "المستخدم قد يكتب بالعامية ويصف الأعراض (اصفرار، بقع، ذبول). اربط الوصف بالمصطلح العلمي من المصادر. أعطِ خطوات عملية وجرعات كما وردت حرفياً. لا تقترح مبيدات غير مذكورة في المصادر."
- **مهم:** `USE_QUERY_REWRITE=true` (التحدي الأساسي: «ليش ورق الزيتون بصفر؟»). أضف لـ eval 3 أسئلة لهجة.
- **بيانات:** نشرات FAO (غالباً PDF إنجليزي) ← النظام يجيب بلغة السؤال ويعمل cross-lingual لأن e5 متعدد اللغات. اذكر هذا كابتكار.
- **بونص:** إدخال صوتي في المتصفح (Web Speech API، `lang="ar-PS"`) — زر ميكروفون في `chat-view.tsx` يملأ الـ textarea. ~20 سطر.

## 4) الإرشاد الصحي الأولي الآمن — متقدم (الصحة)
- **system_prompt_extra:** "لا تشخّص ولا توصي بجرعات غير مذكورة في النشرة. إذا ذكر المستخدم أعراضاً طارئة (ألم صدر، ضيق تنفس، نزيف، فقدان وعي، أفكار انتحارية) ابدأ الإجابة بـ: «⚠️ هذه حالة طارئة، اتصل بالإسعاف 101 فوراً» ثم توقف. استخدم لغة بسيطة لكبار السن."
- **disclaimer:** "المعلومات للتثقيف فقط ولا تغني عن استشارة الطبيب أو الصيدلي."
- **.env:** `MIN_RELEVANCE_SCORE=0.3` (ارفض أكثر — السلامة أولاً). اذكر أنكم اخترتم الدقة على التغطية.
- **ابتكار سريع:** فلتر طوارئ قبل الـ RAG: قائمة كلمات في `generator.py` ← رد ثابت فوري. اختبره في eval كنوع `emergency`.
- **بونص:** وضع صوتي (Text-to-Speech `speechSynthesis`) + خط أكبر.

## 5) مساعد دعم العملاء لشركة برمجيات — سهل
- **system_prompt_extra:** "أعطِ خطوات مرقمة وروابط من التوثيق إن وُجدت. إذا لم تكن متأكداً أو طلب العميل استرداد مال/إلغاء حساب، اقترح فتح تذكرة."
- **escalation_message:** "سأحوّلك لموظف الدعم. افتح تذكرة من …"
- **بيانات:** توثيق مفتوح المصدر (Markdown) + تذاكر CSV (كل صف = سجل).
- **.env:** `CHUNK_SIZE=800`.
- **بونص:** Widget قابل للتضمين: صفحة `/embed` بنفس `ChatView` بدون header + `<iframe>` snippet في README.

## 6) المعرفة الداخلية للمؤسسة — متوسط (HR)
- **التحدي:** RBAC — كل موظف يرى ما يحق له.
- **التنفيذ (جاهز — إعدادات فقط):** مجلدات `raw/public/`, `raw/employees/`, `raw/managers/` ← category. في `domain.yaml`:
  ```yaml
  role_categories:
    anonymous: [public]
    user: [public, employees]
    manager: [public, employees, managers]
    admin: null
  ```
  واجعل `ALLOW_ANONYMOUS_CHAT=false`. اذكر: "الفلترة داخل استعلام Chroma نفسه، فالمقطع غير المسموح لا يصل للـ LLM أصلاً". لإضافة دور `manager` غيّر `role` للمستخدم في SQLite أو أضف endpoint بسيط.
- **إصدارات السياسات:** `version` في اسم المجلد + تعليمات "اعتمد الأحدث".
- **بونص:** موجود: حسابات + لوحة إدارة + رفع مستندات. أضف دور `manager`.

## 7) محلل العقود — متقدم
- **system_prompt_extra:** "استخرج الالتزامات، المدد، الغرامات، شروط الإنهاء، والتجديد التلقائي. صنّف كل بند: 🟢 عادي / 🟡 انتبه / 🔴 خطر، مقارنة بالنموذج المرجعي. اذكر رقم البند والصفحة."
- **بيانات:** `raw/templates/` (نماذج مرجعية) + العقد المرفوع من المستخدم (category=`user_contract`).
- **بونص:** رفع عقد من الواجهة (موجود للأدمن — افتحه للمستخدم) + زر "تقرير المخاطر" يطرح سؤالاً ثابتاً ← ثم `window.print()` لتصدير PDF.

## 8) دليل السياحة والتراث — سهل
- **system_prompt_extra:** "أجب بلغة السائل (عربي/إنجليزي/فرنسي…). انتبه لتعدد أسماء المواقع (كنيسة المهد = Church of the Nativity). عند طلب برنامج زيارة رتّبه زمنياً مع المسافات المذكورة."
- **ابتكار:** أضف لكل موقع ملف JSON بأسمائه البديلة + إحداثياته ← metadata. e5 متعدد اللغات يجعل البحث cross-lingual.
- **بونص:** خريطة Leaflet بالمواقع المستشهد بها.

## 9) مساعد المنح والتمويل — متوسط
- **system_prompt_extra:** "لكل منحة: الجهة، الأهلية، المبلغ، الموعد النهائي، الوثائق المطلوبة — في جدول. إذا أعطى المستخدم وصف مؤسسته قيّم الأهلية بنعم/لا/غير واضح مع السبب من المصدر."
- **metadata:** `deadline` (YYYY-MM-DD) في JSON ← فلترة المنح المنتهية.
- **بونص:** لوحة فرص مرتبة حسب الموعد النهائي (G2 timeline).

## 10) مساعد الأمن السيبراني والامتثال — متقدم
- **system_prompt_extra:** "اربط كل بند من سياسة الشركة بوظيفة/فئة NIST CSF (مثل PR.AC-1). حدّد الفجوات: ضابط مطلوب في NIST وغير مغطّى في السياسة. رتّب التوصيات حسب الأولوية (عالي/متوسط/منخفض)."
- **بيانات:** `raw/nist/` و`raw/company_policy/` ← فلترة منفصلة لكل منهما.
- **.env:** `HYBRID_ALPHA=0.3` (معرفات الضوابط مثل PR.AC-1 ← BM25).
- **بونص:** تقرير فجوات بجدول قابل للتصدير CSV (زر في الواجهة).

## 🧪 التحديات الإضافية المحتملة من المنظمين — جاهزين؟

| التحدي | كيف يتعامل النظام |
|---|---|
| أسئلة بلهجة محكية | Query rewrite → MSA + كلمات مفتاحية؛ البحث بالسؤال الأصلي والمعاد صياغته معاً |
| PDF ممسوح ضوئياً | `inspect_doc` يكشف صفحات بدون نص ← `ocrmypdf -l ara` ثم إعادة الفهرسة |
| جداول | استخراج كـ Markdown، لا تُقطع، مقطع مستقل بعلامة `is_table` |
| مصادر متعارضة | metadata للسنة/الإصدار + قاعدة في الـ prompt: اذكر التعارض واعتمد الأحدث |
| خارج النطاق | كشف في إعادة الصياغة (`in_scope`) + بوابة درجة الصلة + رسالة رفض |
| محادثة متعددة الأدوار | آخر 6 رسائل تُمرر لإعادة الصياغة والتوليد ← "وكم سعرها؟" تُفهم |
