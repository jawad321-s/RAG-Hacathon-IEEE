## قبل التسجيل
- [ ] `make reset` على المستندات النهائية، و`make eval` ليكون تبويب التقييم ممتلئاً
- [ ] اسأل 10 أسئلة متنوعة قبلها حتى تمتلئ لوحة التحليلات
- [ ] جرّب الأسئلة الثلاثة مسبقاً وتأكد من الإجابة
- [ ] أغلق الإشعارات، ونظّف شريط المتصفح

## العرض المباشر أمام المحكّمين
- افتح تبويبين جاهزين: الدردشة + لوحة الإدارة (مسجل دخول).
- عند أسئلتهم المفاجئة: اقرأ السؤال بصوت عالٍ، اكتبه، **اضغط على الاستشهاد** لتُظهر المصدر.
- إذا فشل الإنترنت: `LLM_MOCK=true` في `.env` + أعد تشغيل الـ API بـ `HF_HUB_OFFLINE=1 make api` (حتى لا يحاول تنزيل النماذج) — الإجابات الاستخراجية مع الاستشهادات تعمل بدون إنترنت. والفيديو المسجل هو الخطة البديلة.
